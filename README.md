## 跨宇宙平替 · crossover.html

线上地址：**https://fengzhanxdtpy75.github.io/crossover.html**

漫威 / DC / 黑袍纠察队 / 无敌少侠 / 龙珠 / 一拳超人，六个世界观、**79 位角色**的横向战力对照。核心只有一件事：**平替**——选一个角色，返回另外五个宇宙里"干同一份活"的人，并标出这个平替打了几折。

| 模块 | 说明 |
|---|---|
| **平替雷达** | 选角色 → 五个宇宙各给一个对位，附平替度、战力折扣、共鸣标签和最大落差；点结果可以继续跳转，形成平替链 |
| **横向对照** | 一个区块两种视图：**档位横切**（8 档 × 6 宇宙，同一行 = 同一档）和 **平替矩阵**（12 个"工种"原型 × 6 个宇宙，空格 = 这个世界观没设这个岗），切换不跳页 |
| **换算规则** | 标尺、六维、标签、原型、权重的口径，以及"为什么不能直接约架" |

- 平替度 = **35% 六维 + 25% 定位标签 + 25% 原型 + 15% 战力差**；人工"模板对位"可以覆盖算法第一名（卡片上有金色标记）
- 角色数值是跨宇宙独立口径，和主站单宇宙排名**不能直接混用**
- 素材：Marvel 官网 / DC 官网 / 东映动画《龙珠超》角色页 / AniList。黑袍纠察队与无敌少侠没有可用的官方单独立绘，用 CSS「档案徽记」代替
- 动效：首屏入场、卡片切换 stagger、档位/矩阵切换指示器，均带 `prefers-reduced-motion` 降级；列表用 120×150 缩略图，首屏图片约 500KB
- 校验：`node tools/crossover-check.mjs`（角色数 / 图片是否存在 / 原型 / 平替关系）

### 为什么有两个版本？

- **`index.html`（部署版）**：首屏约 480 KB，图片滚到哪加载哪并被浏览器缓存。**线上访问用这个。**
- **`marvel-standalone.html`（单文件版）**：108 张图全部内嵌，约 4.4 MB。**只有需要「一个文件发给别人 / 断网打开」时才用。**

## 改完之后怎么发布

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\publish.ps1
```

五步：构建两个版本 → 从 **Windows 凭据管理器**读 GitHub Desktop 的 token → 生成清单（含 `crossover.html` 与 `assets/crossover/`）→ **增量上传**（内容没变的自动跳过）→ 删临时 token。

- 只上传不构建：`-SkipBuild` ／ 不要单文件版：`-SkipStandalone`
- **Pages 有 1–3 分钟构建延迟**，刚传完刷新可能还是旧版

## ⚠️ 关于本机的 GitHub 访问

**`Steam++.Accelerator`（Watt Toolkit）正在运行**，监听 `0.0.0.0:80`/`:443` 并往 `hosts` 写入几十条 `127.0.0.1`，
把 `github.com`、`github.io` 等域名劫持到它自己的本地反向代理 —— **这是加速机制，不是屏蔽**。

1. **不要手动删 hosts 里的条目**，加速器会立刻写回来。
2. **Node 默认不信任 Windows 证书库**。`upload-batch.js` 内置两条路径：先走本机代理（`publish.ps1` 用 `node --use-system-ca` 启动），失败改用 DoH 查真实 IP 直连；每条路径都校验响应确实来自 GitHub API。

## 战力体系

战力 0–100 与八个等级**严格单调对应**：

| 档位梗 | 等级 | 战力区间 | 定位 |
|---|---|---|---|
| 夯爆了 | T0 神话级 | 97–100 | 全能宇宙级 / 凌驾一切概念与法则 |
| 夯 | T0.5 传说级 | 90–96 | 影响整个漫威宇宙存亡的存在 |
| 顶级 | T1 史诗级 | 82–89 | 多元宇宙尺度 / 可改写现实法则 |
| 人上人 | T1.5 宇宙级 | 75–81 | 单体宇宙尺度 / 天父级战力 |
| NPC | T2 星域级 | 65–74 | 行星系尺度 / 可威胁整颗星球文明 |
| 人下人 | T3 星球级 | 53–64 | 可摧毁城市 / 地表级破坏力 |
| 拉 | T4 超凡级 | 40–52 | 超越人类极限 / 街区级威胁 |
| 拉完了 | T5 凡人级 | 0–39 | 顶尖特工 / 无超能力 |

每个角色都有 **常态** 与 **巅峰** 两套等级 + 战力 + 13 维属性。

## 数据来源说明

- 英雄数据来自用户提供的原始资料 + **Marvel 官网角色页**逐条核实（`marvel.com/characters/<slug>`）
- Marvel 官网角色库的分页名单通过其前端接口取得：
  `https://www.marvel.com/v1/pagination/grid_cards?componentId=92006&limit=36&offset=<N>&entityType=character&content_type=character`
  （`componentId` 来自 `marvel.com/v1/pages/characters` 里 `filter_grid` 组件的 `component_id`）
- 第 1 页（offset 0）与第 2 页（offset 36）共 72 位，去掉站内已有的重复后共新增 64 位；卡面统一使用 `cdn.marvel.com/content/1x/*.webp` 官方图
- 官方信息极少的角色（Aardwolf、Adam II、Afrershock、Aldebron、Anak 等），条目内已**明确标注为估算**，不假装确证
